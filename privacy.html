Datenschutzhinweis

Home Server Backup ist ein privates Werkzeug, das der Betreiber ausschließlich für sich selbst nutzt. Es richtet sich nicht an andere Personen.

Welche Daten verarbeitet werden

Die Anwendung überträgt Sicherungskopien vom eigenen Heimserver des Betreibers in dessen eigenes Google Drive. Die Sicherungen werden vor dem Hochladen verschlüsselt. Google erhält nur verschlüsselte Dateien.

Die Anwendung nutzt das Google-Recht drive.file und greift damit nur auf Dateien zu, die sie selbst erstellt hat. Sie liest keine anderen Inhalte des Google Drive, keine E-Mails und keine Kontakte.

Daten anderer Personen werden über diese Anwendung nicht erhoben. Es gibt keine Weitergabe an Dritte, keine Analyse und kein Tracking. Diese Seite setzt keine Cookies.

Diese Webseite

Diese Seite wird über GitHub Pages bereitgestellt. Beim Aufruf verarbeitet GitHub technisch notwendige Verbindungsdaten wie die IP-Adresse, siehe Datenschutzerklärung von GitHub. Der Betreiber selbst wertet keine Aufrufe aus.

Zugangsdaten

Das Anmelde-Token liegt ausschließlich auf dem Heimserver des Betreibers. Der Zugriff lässt sich jederzeit unter myaccount.google.com/permissions widerrufen.
