Home Server Backup

Ein privates Werkzeug zur verschlüsselten Datensicherung eines eigenen Heimservers in das eigene Google Drive.

Die Anwendung wird ausschließlich vom Betreiber selbst genutzt. Sie ist kein Angebot an Dritte, und es können sich keine anderen Personen damit anmelden.

Sie verwendet nur das Google-Recht drive.file: Zugriff ausschließlich auf die Dateien, die sie selbst angelegt hat. Andere Inhalte des Google Drive sieht sie nicht.
